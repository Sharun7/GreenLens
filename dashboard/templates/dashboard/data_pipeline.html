Operational Reality
  • Climate hazards, pricing, greenwash scans, and rescoring all have real Celery tasks in the codebase.
  • Registry ingestion is still semi-automated because the platform needs a supplied source file instead of a live bond-registry API.
  • Quarterly PCRS retraining is now part of the beat schedule, matching the stated operating model more closely.
  • Reliability reports already expose missing inputs and downgrade trust when data comes from fallbacks or estimates.
